**Finsage AI** is a state-of-the-art, AI-powered personal finance assistant and analytics workspace. Built using Next.js 16 (App Router), Tailwind CSS, Framer Motion, and Firebase, Finsage integrates real-time data visualization with cutting-edge AI financial planning.

Powered by **Google Gemini 2.5 Flash API** and **Google Cloud Vision OCR**, Finsage automatically extracts transaction amounts from uploaded receipts/bank statements, generates personalized financial advice, tracks savings goals, and adapts its aesthetics dynamically using an intelligent **Time & Festival Theme Engine**.

---

## 🌟 Key Features

* 🎨 **Dynamic Time & Festival Theme Engine**:
  - **Time of Day Modes**: Adapts interface gradients & glowing ambient lighting through *Morning Sunrise* (6 AM), *Day Breeze* (12 PM), *Sunset Twilight* (5 PM), and *Galactic Midnight* (8 PM).
  - **Festival Celebrations**: Vibrant seasonal themes for *Diwali Lights* 🪔, *Holi Color Splash* 🎨, *Navratri Garba* 💃, *Christmas & New Year* 🎄, *Eid Crescent* 🌙, *Patriotic Tricolor* 🇮🇳, and *Spooky Halloween* 🎃.
  - **Framer Motion Micro-Particles**: Floating ambient elements (glowing Diyas, Gulal splashes, Sunbeams, Snowflakes) tailored to each theme.
* 👑 **Admin Role & Access Control**:
  - Festival themes and Auto-Festival mode are protected by Admin role verification (`NEXT_PUBLIC_ADMIN_EMAILS`). Standard users enjoy automatic time-of-day modes and time presets.
* 🌐 **Live System Architecture & Archify Map**:
  - Interactive `/architecture` page and standalone `archify.html` visualizer displaying full component topology, serverless API routes, and end-to-end data processing pipelines.
* 🎯 **Smart Savings Goals & AI Planner**:
  - Set savings targets, track milestone deposits, and receive 3-point actionable AI budgeting recommendations generated by Gemini.
* 🧠 **Gemini AI Financial Copilot**:
  - Context-aware spending analysis, automated transaction categorization, and instant natural language tips.
* 🧾 **AI Receipt OCR & Multi-Format Import**:
  - Upload receipt images or multi-page PDF bank statements for automated line-item extraction powered by Google Cloud Vision.
* 💵 **Multi-Currency Converter**:
  - Dynamic currency switching (INR ₹, USD $, EUR €, GBP £, JPY ¥) with live rate conversions across all metric cards and graphs.
* 📊 **Interactive Analytics**:
  - Comprehensive Recharts components for savings trends, income vs. expense comparison bar charts, and category spending breakdowns.
* 🔐 **Secure Firebase Infrastructure**:
  - Authentication and real-time document persistence powered by Firebase Auth and Cloud Firestore.

## 🏗️ System Architecture & Data-Flow

```mermaid
graph TD
  User[User Browser / Client] --> NextApp[Next.js 16 App Router]

  subgraph Client Layer
    NextApp --> AuthCtx[AuthProvider - Auth & Admin Guard]
    NextApp --> ThemeCtx[ThemeContext - Time & Festival Engine]
    NextApp --> CurrencyCtx[CurrencyContext - Multi-Currency]
  end

  subgraph Application Routes
    NextApp --> Dashboard[Dashboard & Financial Metrics]
    NextApp --> Goals[Savings Goals & AI Planner]
    NextApp --> Upload[Receipt OCR & PDF Parser]
    NextApp --> Architecture[Live Architecture Visualizer]
  end

  subgraph Serverless API Routes
    Dashboard & Goals --> APIInsight[/api/insight - Gemini AI]
    Upload --> APIExtract[/api/amount-extract - Cloud Vision OCR]
    Upload --> APIFile[/api/file-transaction - PDF Parser]
    Dashboard --> APIStats[/api/stats/summary - Metrics Aggregator]
  end

  subgraph Cloud & Database
    AuthCtx --> FirebaseAuth[Firebase Authentication]
    APIStats & Goals & Dashboard --> Firestore[Cloud Firestore DB]
    APIExtract --> CloudVision[Google Cloud Vision API]
    APIInsight --> Gemini[Google Gemini 2.5 Flash]
  end
```

> 💡 **Explore the Live Visual Topology**: Visit the `/architecture` route inside the application or open [`archify.html`](file:///d:/Finsage/archify.html) in your browser.

## ⚙️ Configuration & Setup

### 1. Prerequisites
Ensure you have **Node.js** installed (v18.x or v20.x recommended).

### 2. Environment Variables
Create a `.env.local` file in the root directory and add your credentials:

```env
# Firebase Configuration
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_firebase_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_firebase_messaging_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_firebase_app_id
NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=your_firebase_measurement_id

# Admin Configuration (Comma-separated admin emails)
NEXT_PUBLIC_ADMIN_EMAILS=varshneytanmay75@gmail.com,admin@finsage.com

# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key
```

### 3. Installation & Local Development
Clone the repository, install dependencies, and start the Turbopack dev server:

```bash
git clone https://github.com/Tanmay5555/finsage.git
cd finsage
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Production Build Verification
To compile an optimized production build:

```bash
npm run build
npm run start
```

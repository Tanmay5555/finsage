# Archify — Codebase Architecture & Diagram Skill

Archify is a visual documentation skill that generates interactive, verifiable architecture maps, sequence diagrams, component topologies, and data-flow diagrams for software codebases.

## Capabilities

1. **System Architecture Topology**: Map frontend components, API endpoints, authentication flows, and database schemas.
2. **Data-Flow Diagrams**: Visualize transaction pipelines, OCR receipt processing, and Gemini AI insight generation.
3. **Interactive Visualizer**: Output self-contained standalone HTML visualizer files (`archify.html`) using SVG & Tailwind layout without external dependencies.
4. **Verifiable Documentation**: Maintain synchronized codebase architecture docs (`ARCHITECTURE.md`).

## Workflow

1. Scan project routes, API endpoints, context providers, and cloud integrations.
2. Structure component hierarchy and state bindings.
3. Export interactive HTML diagram (`archify.html`) and markdown architecture manual (`ARCHITECTURE.md`).
